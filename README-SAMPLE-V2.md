# IndiFolks — Sample Website V2

This sample rebuild uses the existing IndiFolks React/Vite project and keeps the existing routes/backend integration while replacing the public-facing experience with a cleaner marketplace-style design.

## Improvements in this sample
- Stronger hero with clear search-first booking flow
- Cleaner reference-inspired navigation
- Better hierarchy and whitespace
- Dedicated art-form discovery cards
- Curated artist cards with rating, location, pricing and verification
- State discovery section
- 3-step booking journey
- Stronger artist CTA
- Responsive mobile navigation/layout
- Existing authentication and route structure preserved
- API stats are used when available, with safe fallback values

## Run
```bash
npm install
npm run dev
```

Optional `.env`:
```env
VITE_API_URL=http://localhost:5000
```
